📋 Production Deployment Guide: Vercel + Supabase
Prerequisites
✅ GitHub account (push code there)
✅ Vercel account (vercel.com - free)
✅ Supabase already live & working
✅ All code pushed to GitHub
PART 1: Deploy Frontend to Vercel (5 minutes)
Step 1: Push Frontend to GitHub
powershell
cd E:\Project\dboard_vscode\frontend
git add .
git commit -m "Production ready frontend"
git push origin main
Step 2: Go to Vercel
Visit https://vercel.com
Click "New Project"
Click "Import Git Repository"
Select Sharmavatsal/dboard_vscode (or your repo name)
Step 3: Configure Vercel Settings
Project Name: seros
Framework: Vite
Root Directory: frontend
Build Command: npm run build
Output Directory: dist
Step 4: Set Environment Variables

In Vercel dashboard, go to "Environment Variables"

Add these:

VITE_API_URL=https://seros-backend.vercel.app
(we'll update this after backend deploys)
Step 5: Deploy

Click "Deploy" and wait (2-3 minutes)

You get: https://seros.vercel.app ✅

PART 2: Deploy Backend to Vercel (10 minutes)
Step 1: Update Backend Files

Create: backend/requirements.txt

flask==3.0.0
flask-cors==4.0.0
flask-sqlalchemy==3.1.1
python-dotenv==1.0.0
gunicorn==21.2.0
psycopg2-binary==2.9.9
sqlalchemy==2.0.23
PyJWT==2.8.1
(add all your dependencies)

Create: Procfile in backend folder

web: gunicorn app.main:app

Create: runtime.txt in backend folder

python-3.11.0
Step 2: Update Backend Config

Edit backend/app.py (or main app file):

python
from flask import Flask
from flask_cors import CORS
import os
from dotenv import load_dotenv

load_dotenv()

app = Flask(__name__)

# CORS for Vercel frontend
CORS(app, resources={
    r"/api/*": {
        "origins": [
            "https://seros.vercel.app",
            "http://localhost:5173",
            "http://localhost:3000"
        ],
        "methods": ["GET", "POST", "PUT", "DELETE"],
        "allow_headers": ["Content-Type", "Authorization"]
    }
})

# Rest of your app code...
Step 3: Push Backend to GitHub
powershell
cd E:\Project\dboard_vscode\backend
git add .
git commit -m "Production ready backend"
git push origin main
Step 4: Go to Vercel
Click "New Project"
Select Sharmavatsal/dboard_vscode again
This time click the backend folder
Step 5: Configure Backend Settings
Project Name: seros-backend
Framework: Other (Python)
Root Directory: backend
Build Command: pip install -r requirements.txt
Start Command: gunicorn app.main:app
Step 6: Set Environment Variables in Vercel

Go to "Settings" → "Environment Variables"

Add all these:

DATABASE_URL=postgresql://user:password@host/db
(copy from Supabase)

SUPABASE_URL=https://your-project.supabase.co
SUPABASE_KEY=your-anon-key

SECRET_KEY=your-random-secret-key

FLASK_ENV=production
Step 7: Deploy

Click "Deploy"

You get: https://seros-backend.vercel.app ✅

PART 3: Connect Frontend to Backend (2 minutes)
Step 1: Update Frontend Env Variable

In Vercel dashboard for seros (frontend):

Go to "Settings" → "Environment Variables"

Update:

VITE_API_URL=https://seros-backend.vercel.app
Step 2: Redeploy Frontend

Click "Deployments" → Click latest → Click "Redeploy"

Wait 1-2 minutes for rebuild.

PART 4: Test Production App (5 minutes)
Open Your Live App
https://seros.vercel.app
Test Features
Login with demo credentials
Upload Excel file
View dashboards
Check if data loads from Supabase
If Login Fails

Check browser console (F12) for errors:

CORS error → Check CORS_ORIGINS in backend
404 error → Backend URL wrong
Network error → Backend not deployed

Just follow this order:

Connect them (2 min)
Test (5 min)
